Welcome to the "Back-end Framework Tutorial"! If you're seeing this page, it means you're interested in developing your own Oinone modules. This might also indicate that you've recently joined Oinone in a technical role. Regardless, your journey in the Oinone technical domain starts here.

The goal of this tutorial is to enable you to gain an in-depth understanding of the most important parts of the Oinone development framework while developing your own Oinone module for expense management. You should study the chapters in the given order, as they cover the process of developing a new Oinone application from scratch in a step-by-step manner. In other words, each chapter relies on the previous one.

:::warning Tip

Before proceeding, make sure to prepare your development environment as per the setup guide.

:::

Ready? Let's get started!
