# 1. Import Tasks
### 1. Function Introduction
When using the import function in any application of the system, a corresponding record will be automatically saved in the import tasks.

:::warning Tip

You can download the imported files in the import tasks.

:::

### 2. Operation Methods
Click "Details" to view the detailed information of the selected import task record.
